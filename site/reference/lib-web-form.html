Standard library · The web

web/form

Imported as import "web/form" as form, its names are then form.…. Every signature below is the one the checker infers.

What a browser sends from a <form>: application/x-www-form-urlencoded as pairs, and multipart/form-data (RFC 7578) as parts, each with its field name, its file name if it was a file, its content type, and its bytes as they were.

import "web/form" as form
match form.parse(content_type, body)          # either kind, by the type
  Ok(parts) -> ...
  Err(why) -> ...
form.value(parts, "email")                    # Some("a@b.c"), the first
form.file(parts, "photo")                     # Some(part): p.filename, p.kind, p.data

content_type is the request's Content-Type header as it came; the boundary is read from it. A body that does not end in the closing boundary, or a part without its blank line, is refused.
