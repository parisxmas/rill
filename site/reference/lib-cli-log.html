Standard library · The command line

cli/log

Imported as import "cli/log" as log, its names are then log.…. Every signature below is the one the checker infers.

A log: lines on standard error with the time, the level and where they came from, and a level below which nothing is said.

import "cli/log" as log
l = log.from_env("http")             # the level from RILL_LOG, or info
log.info(l, "listening on " + int_to_str(port))
log.warn(l, "slow request")
log.debug(l, "headers: " + show(h))  # said only at debug or below

2026-09-15T21:04:05Z  INFO  http  listening on 8080

A logger is a value with a name and a level; at(l, log.debug_level()) gives one that says more, quiet(l) one that says only errors. There is no global switch, because there are no globals: a program makes one logger in main and hands it to what needs it, which is also how it gives a part of itself a name of its own with named(l, "db"). A line is written whole with one call, so lines from strands do not interleave.
