Standard library · Cryptography

crypto/sha1

Imported as import "crypto/sha1" as sha1, its names are then sha1.…. Every signature below is the one the checker infers.

SHA-1 and base64, written in Rill. The WebSocket handshake needs both, and they are a fair test of the language's bit operations: everything here is 32-bit arithmetic emulated on 64-bit integers by masking after each step.

import "text/str" as str
str.hex_encode(sha1.sha1("abc"))   # => a9993e364706816aba3e25717850c26c9cd0d89d
sha1.base64(sha1.sha1("abc"))     # => qZk+NkcGgWq6PiVxeFDCbJzQ2J0=
