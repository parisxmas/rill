Standard library · Data formats

data/yaml

Imported as import "data/yaml" as yaml, its names are then yaml.…. Every signature below is the one the checker infers.

YAML, written in Rill — the part configuration files actually use: nested mappings by indentation, - sequences, scalars, comments, and lists of mappings. Not supported, and deliberately so: anchors and aliases, multiple documents, flow collections, block scalars, tags.

Values land in the JSON module's Json type, so a parsed document can be printed as JSON without any conversion.

Types

YParsed

What is left to read, and the value read so far. It used to be a line number into the list of lines, and every step then cost a walk from the front to reach it — nth to read a line, len to ask whether there were any left. Both are linear in a list, both were called per line, and an eight-hundred-entry config took fifty-five milliseconds to read because of it. Carrying the rest of the lines instead makes each step O(1) and the whole parse linear.

  • YParsed(value: Json, rest: List(Str))

How far in the block below is indented, when there is one.
