Standard library · Numbers

num/decimal

Imported as import "num/decimal" as decimal, its names are then decimal.…. Every signature below is the one the checker infers.

Decimal numbers with a fixed number of places: money, and anything else where 0.1 + 0.2 has to be 0.3.

A Decimal is an integer count of units and a scale, the number of places: Decimal(1250, 2) is 12.50. Adding and comparing align the scales; multiplying keeps every place and rounds only when asked; dividing takes the places to keep and how to round. The count is an Int, so eighteen digits in all is the limit, and a result past it is the wrong number rather than an error — the same as Int itself.

import "num/decimal" as dec
price = dec.parse("19.99")?               # Decimal(1999, 2)
total = dec.mul(price, dec.from_int(3))   # 59.97
vat = dec.round_to(dec.mul(total, dec.parse("0.20")?), 2, dec.HalfEven)
println(show(dec.add(total, vat)))        # "71.96"
