Standard library

The standard library

43 modules, all written in Rill, imported by their path under lib/: import "data/json" as json. The compiler finds them beside its own bin/ in a packaged toolchain, or through RILL_PATH. These pages are what rill doc lib writes: the comment above each declaration, and the signature the checker infers for it.

Text lib/text

  1. fmttext/fmtText laid out and numbers spelled: a template with slots, padding by width, a float to so many places, thousands separated, a size in bytes, an ordinal, a table with its columns lined up.
  2. pathtext/pathFile paths as text: joining, taking apart, tidying.
  3. regextext/regexRegular expressions: a small backtracking matcher, written in Rill.
  4. strtext/strStrings, past what the prelude gives.

Data formats lib/data

  1. checksumdata/checksumThe two checksums a file format is likely to ask for: CRC-32 (IEEE 802.3, the one in zip, gzip and PNG) and Adler-32 (zlib's).
  2. csvdata/csvCSV, read and written, as RFC 4180 has it: a field is quoted when it holds the separator, a quote, or a line break; a quote inside a quoted field is doubled; a line ends in \n or \r\n.
  3. deflatedata/deflateDEFLATE (RFC 1951) both ways, and the two envelopes it travels in: zlib (RFC 1950) and gzip (RFC 1952).
  4. jsondata/jsonJSON, written in Rill: a recursive-descent parser and a printer.
  5. yamldata/yamlYAML, written in Rill — the part configuration files actually use: nested mappings by indentation, - sequences, scalars, comments, and lists of mappings.

Collections lib/coll

  1. dequecoll/dequeA queue with both ends open: push and pop at the front or the back, each in constant time on average.
  2. heapcoll/heapA priority queue: the least element is always at the top, and taking it costs a logarithm.
  3. setcoll/setA set of values: a hash table with only keys, so membership is a lookup rather than a walk.

Numbers lib/num

  1. bigintnum/bigintIntegers of any size, written in Rill.
  2. colnum/colColumn aggregates, vectorized by hand.
  3. decimalnum/decimalDecimal numbers with a fixed number of places: money, and anything else where 0.1 + 0.2 has to be 0.3.
  4. gridnum/gridgrid — arrays of numbers with a shape, the way NumPy has them.

The web lib/web

  1. formweb/formWhat a browser sends from a <form>: application/x-www-form-urlencoded as pairs, and multipart/form-data (RFC 7578) as parts, each with its field name, its file name if it was a file, its content type, and its bytes as th
  2. httpweb/httpA small HTTP/1.1 server, written in Rill on top of the socket builtins.
  3. mimeweb/mimeThe media type a file is served as, from its name: mime.of_path("a/b.png") is image/png.
  4. tlsweb/tlsTLS over a socket, through OpenSSL: https:// as a client, and served.
  5. tmplweb/tmplThe runtime half of the template engine: what a generated template calls.
  6. urlweb/urlURLs taken apart and put together (RFC 3986): the scheme, who, the host, the port, the path, the query, the fragment; a query as pairs; a relative reference resolved against a base; percent-encoding both ways.
  7. wsweb/wsWebSocket (RFC 6455) on top of the socket builtins: the handshake, and text or binary frames in both directions.

The network lib/net

  1. dnsnet/dnsA name to its addresses, through the system's resolver — /etc/hosts, the nameservers it is configured with, whatever else it consults.
  2. udpnet/udpUDP: datagrams sent and received, each one whole, with the sender's address on the ones that arrive.

Databases lib/db

  1. kvdb/kvA key–value store on disk: a B+ tree of 4 KB pages, a page cache, and a write-ahead log — the shape SQLite's file layer has, in Rill, for one process at a time.
  2. oxidbdb/oxidbA client for OxiDB's document engine, written in Rill.
  3. oxirecdb/oxirecA client for OxiDB's recommendation engine, written in Rill.
  4. oxirespdb/oxirespA client for OxiDB's in-memory key-value engine, written in Rill.
  5. oxisqldb/oxisqlA client for OxiDB's SQL engine, written in Rill.
  6. oxitsdbdb/oxitsdbA client for OxiDB's time-series engine, written in Rill, speaking the server's binary wire rather than its JSON one.
  7. oxiwiredb/oxiwireOxiWire — the binary format OxiDB's native wire speaks, encoded and decoded in Rill.

The command line lib/cli

  1. argscli/argsCommand-line arguments: what a program takes, said once, and then parsed, checked and explained from that one saying.
  2. envcli/envThe process and its surroundings: environment variables, the working directory, the machine's name, the process id.
  3. logcli/logA log: lines on standard error with the time, the level and where they came from, and a level below which nothing is said.
  4. proccli/procRunning another program: a command line handed to the shell, its output collected, its exit status read.

Cryptography lib/crypto

  1. passwdcrypto/passwdStoring a password, which is storing something you must never be able to read back.
  2. sha1crypto/sha1SHA-1 and base64, written in Rill.
  3. sha2crypto/sha2SHA-256 and SHA-512 (FIPS 180-4), and HMAC over each (RFC 2104), written in Rill.

Randomness lib/random

  1. rndrandom/rndRandom numbers, from a generator that is a value.
  2. uuidrandom/uuidUUIDs (RFC 9562): the random kind, version 4, and the time-ordered kind, version 7, whose first 48 bits are the millisecond it was made, so a column of them sorts by when.

Time lib/time

  1. clocktime/clockClocks: the monotonic one for measuring, the wall one for dating.
  2. datetime/dateCivil dates and times, in UTC and nothing else.
