Standard library · The web

web/url

Imported as import "web/url" as url, its names are then url.…. Every signature below is the one the checker infers.

URLs taken apart and put together (RFC 3986): the scheme, who, the host, the port, the path, the query, the fragment; a query as pairs; a relative reference resolved against a base; percent-encoding both ways.

import "web/url" as url
match url.parse("https://user@example.com:8443/a/b?x=1&y=two#top")
  Some(u) -> u.host                  # "example.com"; u.port 8443; u.path "/a/b"
  None -> ...
url.query_pairs("x=1&y=two%20words") # Cons(("x", "1"), Cons(("y", "two words"), Nil))
url.resolve("https://example.com/a/b/c", "../d?q")   # "https://example.com/a/d?q"
url.encode("a b&c")                  # "a%20b%26c"

A Url is a record; text writes it back, and a part that was not there is empty (port is -1). Nothing is decoded on the way in — the path and query are as they were written — so decode what you look at.

Functions

fn parse(s: Str) -> Option(Url)

A URL with a scheme and //, or None. A path-only reference is not a URL; resolve it against one.

fn text(u: Url) -> Str

fn port_of(u: Url) -> Int

The port, or the scheme's usual one: 80, 443, 21, 22, 25.

fn origin(u: Url) -> Str

The scheme, host and port alone: https://example.com:8443.

fn query_pairs(query: Str) -> List((Str, Str))

a=1&b=two%20words as decoded pairs; a key without = has the value "".

fn query_text(pairs: List((Str, Str))) -> Str

The pairs as a query, each side encoded.

fn query_get(query: Str, name: Str) -> Option(Str)

The first value under name, decoded.

fn encode(s: Str) -> Str

Percent-encoding of everything but the unreserved characters — letters, digits, - . _ ~ — so the result is safe anywhere in a URL.

fn decode(s: Str) -> Str

%xx back to bytes and + to a space, as a form sends them; a % not followed by two hex digits is kept as it is.

fn resolve(base: Str, reference: Str) -> Str

reference seen from base, as a browser follows a link: absolute references stand; //host/x keeps the scheme; /x keeps the host; x, ./x and ../x are joined to the base's path with the dots resolved; ?q and #f alone replace only that part.
