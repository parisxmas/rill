Standard library · The network

net/udp

Imported as import "net/udp" as udp, its names are then udp.…. Every signature below is the one the checker infers.

UDP: datagrams sent and received, each one whole, with the sender's address on the ones that arrive. A socket is a descriptor as a TCP one is, and a receive parks the strand rather than the worker, so a server with a datagram socket and ten connections serves all eleven.

import "net/udp" as udp
sock = udp.open(9000)?               # or udp.open(0), and udp.port_of(sock)
udp.send_to(sock, "127.0.0.1", 9001, "ping")
p = udp.recv_from(sock)              # a Packet: p.from, p.port, p.data
sock_close(sock)

Addresses are dotted IPv4, as the TCP calls take them; net/dns turns a name into one. A datagram is at most 65,507 bytes, and a longer one is refused rather than cut.
