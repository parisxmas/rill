coll/deque

Imported as import "coll/deque" as deque, its names are then deque.…. Every signature below is the one the checker infers.

A queue with both ends open: push and pop at the front or the back, each in constant time on average. A deque is a value — every operation gives a new one and leaves the old as it was — so it is the queue to keep in a loop's state or a strand's, where a list would cost a walk to reach its far end.

import "coll/deque" as dq
q = dq.push_back(dq.push_back(dq.new(), "first"), "second")
match dq.pop_front(q)
  Some((x, rest)) -> ...             # "first", and the queue without it
  None -> ...
dq.of(list), dq.items(q), dq.size(q)

Two lists, one for each end, the front's in order and the back's reversed; when one runs dry the other is turned round to feed it, which is the walk a plain list would make on every pop, made once in a while.
