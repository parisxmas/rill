Standard library · The web

web/mime

Imported as import "web/mime" as mime, its names are then mime.…. Every signature below is the one the checker infers.

The media type a file is served as, from its name: mime.of_path("a/b.png") is image/png. The table is the hundred-odd types a web server meets; anything else is application/octet-stream, which is what a browser treats as "download it".

import "web/mime" as mime
mime.of_path("site/index.html")      # "text/html"
mime.of_ext("json")                  # "application/json"
mime.is_text("application/json")     # true: served with a charset
mime.ext_of("image/jpeg")            # Some("jpg")
