db/oxirec

Imported as import "db/oxirec" as oxirec, its names are then oxirec.…. Every signature below is the one the checker infers.

A client for OxiDB's recommendation engine, written in Rill.

The wire is oxiwire.rill, the same binary one the document, time-series and SQL clients use. This engine is off unless the server was started with OXIDB_REC.

What it holds is co-occurrence: baskets go in, and it answers what tends to turn up beside a thing. A basket is an id and a list of items at a moment; nothing else about them is kept.

Time is in seconds here, not the milliseconds the time-series engine takes — and it matters more than a unit usually does, because scores decay with age. A query is scored against now unless given a moment of its own, so baskets tracked with old timestamps answer with nothing at all rather than with an error. If rec_related comes back empty, check the two clocks before checking the data.
