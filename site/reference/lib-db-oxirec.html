fn rec_track(fd: Int, model: Str, basket_id: Int, item_names: List(Str), at: Int) -> Result(Json, Str)

One basket: who it was, what was in it, and when. at is epoch seconds; the server's own clock is used when it is left out, which rec_track_now does.

# not run
import "db/oxirec"
rec_track(fd, "shop", 42, Cons("bread", Cons("butter", Nil)), 1700000000)   # a basket, at a moment in seconds

fn rec_related(fd: Int, model: Str, item_name: Str, spec: List(Field)) -> Result(Json, Str)

What turns up beside one item. spec is built with the options below, or Nil for the engine's own defaults.

# not run
import "db/oxirec"
rec_names(rec_related(fd, "shop", "bread", rec_limit(3, rec_scoring("llr", Nil)))?)

fn rec_for_basket(fd: Int, model: Str, item_names: List(Str), spec: List(Field)) -> Result(Json, Str)

What to put beside a basket somebody already has. rec_without keeps what is already in it out of the answer.

# not run
import "db/oxirec"
rec_names(rec_for_basket(fd, "shop", Cons("bread", Cons("tea", Nil)), rec_without(Cons("milk", Nil), Nil))?)

fn rec_at(seconds: Int, rest: List(Field)) -> List(Field)

The moment to score against, in epoch seconds. Without it the server's clock is used, which is what makes old test data answer with nothing.

import "db/oxirec"
rec_at(1700000000, Nil)   # => Cons(Field(ts, JInt(1700000000)), Nil)
