Standard library · Cryptography

crypto/sha2

Imported as import "crypto/sha2" as sha2, its names are then sha2.…. Every signature below is the one the checker infers.

SHA-256 and SHA-512 (FIPS 180-4), and HMAC over each (RFC 2104), written in Rill. A digest is returned as raw bytes in a Str; hex spells one out. Keys and messages are bytes too: any Str will do.

import "crypto/sha2" as sha
sha.hex(sha.sha256("abc"))         # "ba7816bf…f20015ad"
tag = sha.hmac_sha256(secret, body)
sha.same(tag, sent)                # compared in constant time

SHA-256 is 32-bit arithmetic on 64-bit integers, masked after each step; SHA-512 is the machine's own 64-bit arithmetic, which wraps as the algorithm wants and shifts logically, so nothing has to be masked. The schedule and the working state are buffers rather than lists, and a block is read straight out of the message.
