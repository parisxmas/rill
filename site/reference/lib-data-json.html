data/json

Imported as import "data/json" as json, its names are then json.…. Every signature below is the one the checker infers.

JSON, written in Rill: a recursive-descent parser and a printer.

Parsing functions return a Parsed — the value together with where it stopped, or why it stopped — because that is how a recursive-descent parser threads position through immutable data. A failure is a Parsed like any other and rides out through the same returns a value does; parse is the only one that turns it into a Result, because the caller is the only one with anywhere else to put it.

fn parse(text: Str) -> Result(Json, Str)

A document is one value and then nothing but space. Text after that value means the document was not what it claimed to be, and a parser that returns the value anyway has answered a question nobody asked: nonsense is not the JSON document null with a remark after it.

str_get answers -1 past the end, so every byte test here doubles as the end-of-text test, and the text running out is never mistaken for a byte.

fn keyword(s: Str, i: Int, word: Str, value: Json) -> Parsed

The three literals used to be taken on their first byte and their length alone, so nul and true_enough were read as null and true.

fn parse_string(s: Str, i: Int, acc: Str) -> Parsed

" is 34, \ is 92.

The bytes up to the next " or \ come off in one piece. Nearly every string in a document holds no escape at all, and taking those a byte at a time cost a string the square of its length — a fresh copy of everything read so far, per byte read.

fn joined(acc: Str, run: Str) -> Str

A string with no escape in it is one run, and one run onto nothing is the run itself — worth saying, because it is the case nearly every string is.

fn parse_string_at(s: Str, i: Int, acc: Str) -> Parsed

Reached only on a ", a \, or the end: plain_end stops at nothing else.

fn parse_unicode(s: Str, i: Int, acc: Str) -> Parsed

\uXXXX is a UTF-16 unit: a character below 65536 outright, or one half of a surrogate pair spelling one above it — \uD83D\uDE00 is a single character. Either way it goes in as the bytes UTF-8 spells it with. A half with no other half is U+FFFD, the replacement character, which is what text that has lost a piece is.

fn parse_number(s: Str, i: Int) -> Parsed

parse_value only comes here on a byte a number may begin with, so there is always at least one to take. What is taken is not checked past that: 1.2.3 is handed to str_to_float and becomes whatever that makes of it.

fn number_of(text: Str) -> Json

JSON has a single number type, but a document id or a count is exact and a measurement is not. A literal that never showed a decimal point or an exponent stays an integer, so it prints back exactly the way it arrived — %g would turn an id of 1234567 into 1.23457e+06.

fn to_string(j: Json) -> Str

Written into one builder rather than assembled out of pieces: the old printer built a string per value and a list of them per array, then joined those — so a document of six hundred records made thousands of strings on the way to one. Nothing here makes a string but the builder.
