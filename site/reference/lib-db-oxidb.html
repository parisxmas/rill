fn hello(fd: Int) -> Result(Json, Str)

The handshake, and the one command whose reply is not on the wire the request was written in: the server answers hello before it has looked at the format, so what comes back is JSON whatever went out, and it is the server's own shape rather than the usual envelope — {"ok":true, "server":{...}}. So this reads either, and hands back what the reply says about the server.

# not run
import "db/oxidb"
info = hello(fd)?
server_name(info)   # "oxidb"

fn find_page(fd: Int, collection: Str, query: Json, sort: Json, limit: Int, skip: Int) -> Result(Json, Str)

One page of a query: limit documents, the first skip of them passed over. The sort has to be given, because a page is only a page if the order is the same each time.

# not run
import "db/oxidb"

fn aggregate(fd: Int, collection: Str, pipeline: Json) -> Result(Json, Str)

A pipeline — a list of stages, $match, $group, $sort, $facet and the rest, each a document like {"$group": {"_id": "$role", "n": {"$sum": 1}}} — and what comes out of the end of it.

# not run
import "db/oxidb"
pipeline = JArr(Cons(JObj(Cons(field("$group", JObj(Cons(field("_id", text("$role")), Cons(field("n", JObj(Cons(field("$sum", int(1)), Nil))), Nil)))), Nil)), Nil))
docs(aggregate(fd, "people", pipeline)?)   # one document per role, with its count

fn proc_status(fd: Int) -> Result(Json, Str)

What the server process itself is doing: how much memory it is holding, how busy it is, how many threads it has, how long it has been up. Nothing about the data, so a page can show it to anyone who may see the page.

# not run
import "db/oxidb"
st = proc_status(fd)?
rss_mb(st)   # the server's resident memory, in MB
