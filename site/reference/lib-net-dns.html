Standard library · The network

net/dns

Imported as import "net/dns" as dns, its names are then dns.…. Every signature below is the one the checker infers.

A name to its addresses, through the system's resolver — /etc/hosts, the nameservers it is configured with, whatever else it consults. The lookup is a wait, so it is declared blocking: the strand parks while a helper thread asks, and the worker goes on with the others.

import "net/dns" as dns
match dns.lookup("example.com")
  Ok(addrs) -> ...                   # Cons("93.184.215.14", ...), IPv4 first
  Err(why) -> ...
dns.ipv4("localhost")                # Some("127.0.0.1"): the first IPv4, for tcp_connect
dns.is_ipv4("10.0.0.1")              # true — no lookup needed

Functions

fn lookup(name: Str) -> Result(List(Str), Str)

Every address the name has, IPv4 addresses first and then IPv6, or why there are none.

fn ipv4(name: Str) -> Option(Str)

The first IPv4 address, which is what tcp_connect and udp.send_to take.

fn is_ipv4(s: Str) -> Bool

Four numbers of at most three digits, each below 256, with dots between.
