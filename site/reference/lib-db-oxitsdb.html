db/oxitsdb

Imported as import "db/oxitsdb" as oxitsdb, its names are then oxitsdb.…. Every signature below is the one the checker infers.

A client for OxiDB's time-series engine, written in Rill, speaking the server's binary wire rather than its JSON one.

The wire itself — the framing, the tags, the reply envelope — is oxiwire.rill, shared with the document client. What is here is the time-series surface written on top of it: what a point is, what a query may ask for, and how to read the series that come back.

Every request names the engine as well as the command: the server mounts the time-series engine beside the document and SQL ones, and engine is what tells them apart. It is off unless the server was started with OXIDB_TSDB.

fn ts_point(measurement: Str, tags: List(Field), fields: List(Field), at: Int) -> Json

A point is a measurement, a moment, any number of string tags and one or more named fields. at is epoch milliseconds.
