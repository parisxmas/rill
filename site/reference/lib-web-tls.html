Standard library · The web

web/tls

Imported as import "web/tls" as tls, its names are then tls.…. Every signature below is the one the checker infers.

TLS over a socket, through OpenSSL: https:// as a client, and served. A connection reads and writes as a socket does — read gives what has arrived and "" when the peer is done, write sends all of it — and the waits are blocking externs, so a strand parks for a handshake or a read and the worker goes on with the others.

import "web/tls" as tls
c = tls.connect("example.com", 443)?           # verified against the system's roots
tls.write(c, "GET / HTTP/1.1\r\nHost: example.com\r\nConnection: close\r\n\r\n")
reply = tls.read_all(c)                        # everything, until the server closes
tls.disconnect(c)
tls.get("example.com", 443, "/")               # the three lines above

s = tls.listen(8443, "cert.pem", "key.pem")?   # a server with its certificate
c = tls.accept(s)?                             # one connection, handshake done

connect checks the certificate — the chain against the roots the system keeps, and the name against the host asked for — and refuses one that does not check, saying why. connect_insecure skips the check, for a certificate you signed yourself; nothing else should use it.

The library is OpenSSL 3 — Homebrew's openssl@3 on macOS, libssl on Linux — linked when this module is imported.

Functions

fn connect(host: Str, port: Int) -> Result(Conn, Str)

A verified connection to host:port, the name resolved on the way.

fn connect_insecure(host: Str, port: Int) -> Result(Conn, Str)

The same without checking the certificate.

fn read(c: Conn) -> Str

What has arrived, up to 64 KB; "" when the peer has closed or the connection failed.

fn read_all(c: Conn) -> Str

Everything until the peer closes.

fn write(c: Conn, s: Str) -> Int

Writes all of it; the bytes written, or -1.

fn disconnect(c: Conn) -> Unit

Ends the session and closes the socket.

fn listen(port: Int, cert_path: Str, key_path: Str) -> Result(Server, Str)

A listening socket with a certificate chain and its key, both PEM files.

fn accept(s: Server) -> Result(Conn, Str)

The next connection, its handshake done. The context is the server's, so a Conn from here is ended with disconnect and the context stays.

fn stop(s: Server) -> Unit

fn get(host: Str, port: Int, path: Str) -> Str

GET path over a fresh connection, closed after; the raw reply, with http's status_of and response_body to take it apart, or the error text.

fn ask(host: Str, port: Int, method: Str, path: Str, headers: List(Str), body: Str) -> Str
